# Cambiador de Color de Fondo

## ¿Qué es este proyecto?

Este proyecto es una página web simple que cambia el color de fondo de la página de forma aleatoria cuando se presiona un botón. Además, muestra el código hexadecimal del color seleccionado.

---

## ¿Por qué se creó?

El propósito de este proyecto es demostrar el uso básico de HTML, CSS y JavaScript para:
- Manipular el DOM y aplicar estilos dinámicos.
- Usar arrays y funciones matemáticas (`Math.random()`) para generar colores aleatorios.
- Entender cómo integrar lógica de programación en una página web sencilla.
  
Este ejemplo también sirve para aprender y practicar conceptos fundamentales en desarrollo web front-end.

---

## ¿Cómo funciona?

- La página contiene un botón con un evento `onclick` que ejecuta la función `cambiarColor()`.
- Dentro de esta función:
  - Se define un array con los caracteres hexadecimales permitidos.
  - Se genera un color hexadecimal aleatorio concatenando 6 caracteres elegidos aleatoriamente usando `Math.random()`.
  - El color generado se aplica dinámicamente al fondo de la página usando JavaScript.
  - El código hexadecimal del color actual se muestra en pantalla para referencia visual.

---

## Instrucciones para usar

1. Clona o descarga el repositorio.
2. Abre el archivo `index.html` en cualquier navegador moderno.
3. Presiona el botón "Cambiar Color" para cambiar el fondo y ver el código hexadecimal.
